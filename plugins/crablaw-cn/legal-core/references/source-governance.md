# Research Source Governance

## Purpose

This implementation was designed from the repository's own Matter Gate, schemas, audit plan, and
general legal-workflow engineering requirements. The external repository below was reviewed only to
identify high-level capability categories and must not be copied into CrabLaw-CN.

## External research reference

- Repository: `THUYRan/Legal-Skills-Chinese`
- Snapshot reviewed: `d844a25f6d5e6eff4999774a9ab0f79f7cb9d22d`
- Published terms observed in its README: CC BY-NC-ND 4.0
- Allowed implementation input: abstract capability names and general workflow ideas
- Prohibited implementation input: skill prose, tables, templates, examples, numbering, images, or
  other distinctive expression
