# 连接器

> **MCP 安全暂停**：当前版本没有可执行 MCP 配置、内置服务或已连接来源；不得按本文下载、安装、填写凭证、修改设置或连接服务。以下仅是历史/未来能力分类，恢复前必须另行通过安全、宿主、发布与升级重启审查。

## 工具引用机制

插件文件中的双波浪线类别标记仅表示未来能力类别；当前不会解析为已连接工具。工作流应使用用户导出的 CSV/Excel、本地文件或直接粘贴的数据。

## 历史/未来能力目录（当前不可用）

| 类别 | 历史/未来候选 | 当前安全降级 |
|---|---|---|
| 收款 | 支付宝、微信支付 | 用户从商户平台导出账单后上传 |
| 团队 IM / 日历 | 钉钉、飞书 | 用户粘贴消息、日程或上传导出文件 |
| 在线文档 / 表格 | 腾讯文档等 | 用户下载文件后上传 |
| CRM / SCRM | 企业微信、有赞、HubSpot 等 | 用户导出客户、线索、订单或工单数据 |
| 财务 / 记账 | 用友好会计、金蝶精斗云等 | 用户导出 CSV/Excel 或粘贴报表 |
| 电子签 | 历史业务候选 | 插件只产出草稿，由用户自行审阅和签署 |
| 设计、邮件、网盘 | 历史业务候选 | 插件只产出内容或处理用户提供的文件 |

候选产品名不表示官方支持、当前可用、已安装或已连接，也不是产品推荐。

## 未来恢复审查

任何类别恢复前至少需要：供应商真实性与权限边界、身份/同意、数据与
保留策略、精确端点和协议 E2E、最小 scope、失败关闭、宿主激活、旧版
升级并重启 CrabCode、确定性发布、回滚及公网字节复核。证据不足时保持
`blocked / not connected`。
